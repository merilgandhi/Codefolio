## Scope decisions to preserve

1. Implement all four phases and all timeline tasks, including live preview even though Phase 1 labels it a bonus.
2. Keep `templateId` on the User model as explicitly requested. Earlier planning described it under portfolio presentation; that does not override the brief.
3. Provide an actual backend `GET /:username` lookup handler. React Router may assist navigation but is not a substitute for the specified backend behavior.
4. Use canonical `/:username` links. Support the showcase example `/user/:username` as a redirect alias so both examples in the brief work.
5. Choose two distinct themes; Minimalist, Cyberpunk and Corporate are examples, not a requirement for three themes.
6. Use Nodemailer, satisfying both the prerequisites and Week 4. Phase 4 permits SendGrid as an alternative, but no substitution is needed.
7. Custom-domain redirect simulation is explicitly permitted. It must work and be documented as a simulation; a nonfunctional input or badge does not satisfy it. Full DNS mapping remains an alternative implementation.
8. Preserve React Helmet as the specified SEO tool. Evaluate package compatibility with the selected React version during implementation; document and resolve any conflict before substituting a library.
9. Payment processing is not explicitly required. A working Pro tier, badge and permitted domain feature are required. The user subsequently requested and approved self-service demo plan selection without payment; that additional feature is now implemented.
10. Screenshot and resume URLs are required; upload storage is not explicitly required. URL-based support is sufficient unless the user expands scope.
11. The four-week sequence is a milestone guide, not evidence that any task is complete or an agreed calendar deadline.
